지금, 타이머 사용 방법

  1. 빠르게 시작하기빠른 시작의 1~10분 버튼을 누르면 그 시간으로 바로 카운트다운이 시작돼요.
  2. 원하는 시간 정하기직접 설정에 분(0~999)과 초(0~59)를 넣고 화살표 버튼(또는 Enter)을 누른 뒤 시작하기를 누르세요.
  3. 멈추고 다시 하기일시정지 후 계속하기로 이어 가고, 왼쪽 동그라미 버튼으로 처음 시간으로 되돌려요.
  4. 크게 띄우기전체 화면을 누르면 타이머만 크게 보여요. 발표장·교실 화면에 띄우기 좋아요.
  5. 색 바꾸기오늘의 색에서 눈에 잘 띄는 보색 조합을 골라요. 고른 색은 다음에도 기억해요.
