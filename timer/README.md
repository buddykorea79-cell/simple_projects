# 지금, 타이머

멀리서도 잘 보이는 큰 글씨 카운트다운 타이머 (순수 HTML/CSS/JS).

## 사용 방법

- **빠른 시작**: 1~10분 버튼을 누르면 바로 시작.
- **직접 설정**: 분(0~999)·초(0~59) 입력 → 화살표(또는 Enter) → *시작하기*.
- **일시정지 / 계속하기 / 초기화**, **전체 화면**으로 크게 띄우기, **오늘의 색**에서 보색 테마 선택.
- 단축키: `Space` 시작·일시정지 · `R` 초기화 · `F` 전체 화면 · `Esc` 전체 화면 끄기.
- 끝나면 알림음 3번 (소리 버튼으로 끄기). 다른 탭에 있어도 실제 시간 기준으로 정확히 흐릅니다.

테스트: `node --test timer/tests/*.test.mjs` (루트에서 `npm test`에 포함)
