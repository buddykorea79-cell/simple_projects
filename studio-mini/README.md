# Donkey-Studio Mini — 동키의 5번째 잡동사니

드론·액션캠 영상에서 AI가 장면을 골라 다듬고 보정해 MP4로 저장하는 로컬 앱, Donkey-Studio Mini의
소개·다운로드·설치·사용 방법을 한 페이지로 모은 곳입니다.

앱 소스는 이 저장소가 아니라 GitHub https://github.com/buddykorea79-cell/Donkey-Studio-mini (로컬: `D:\Donkey-Studio-Mini`)에 있습니다.
이 페이지의 **ZIP 내려받기**는 GitHub의 `main` 최신본 ZIP을 바로 가리키므로, 앱을 새로 올려도 여기서 따로 할 일은 없습니다.

| 경로 | 내용 |
| --- | --- |
| `index.html` · `studio.css` · `studio.js` | 소개 페이지 (링크 주소는 `studio.js` 맨 위 `REPO`) |
| `images/donkey.svg` | 앱의 동키 캐릭터 |
| `images/shot-*.webp`, `images/theme-*.webp` | 실제 앱 화면 캡처 (합성 샘플 영상 사용, 개인 영상 아님) |

- 버전 표기(`data-version`, 현재 0.1.0)는 `index.html` 에서 직접 고칩니다.
- 화면 캡처는 자동으로 바뀌지 않습니다. 앱 화면이 크게 바뀌면 다시 캡처해 주세요.
