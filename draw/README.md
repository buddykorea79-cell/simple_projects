# 모두의 추첨

구글 폼·CSV 참가자 명단으로 경품을 추첨하는 웹앱. 설계는 [DESIGN.md](DESIGN.md).

## 사용 방법

1. **참가자 명단 불러오기** — 셋 중 하나
   - **CSV · 엑셀 파일**: `이름`, `휴대폰`(또는 전화·연락처) 열이 있는 `.csv` · `.xlsx` · `.xls` 파일을 끌어다 놓기. 표 제목 줄이 위에 있어도 되고, 시트가 여러 개면 고를 수 있음.
   - **게시된 구글 시트**: 시트 [파일] → [공유] → [웹에 게시] → CSV 링크 붙여 넣기. ⚠️ 행사 후 게시 중단.
   - **Apps Script (권장)**: [`apps-script/Code.gs`](apps-script/Code.gs)를 응답 시트의 Apps Script에 붙여 넣고 웹 앱으로 배포 → `…/exec` 주소 붙여 넣기. 가려진 이름·번호만 받아 옴.
   - 처음이면 **샘플 데이터로 체험**.
2. **추첨하기** — 차수, 경품, 당첨 인원 입력 → 방식 선택 → 진행 방식 선택 → 추첨 시작.
   - 로또 볼 (1~10명) · 카드 뒤집기 (10~60명) · 서바이벌 (수십~수백 명, 항상 3단계)
   - **수동 추첨**: Space·클릭으로 한 명(한 단계)씩 · **일괄 추첨**: 클릭 없이 한 명씩 차례로 자동 공개, Space로 일시정지
   - 무대 단축키: `Space`/`→` 수동은 다음, 일괄은 일시정지·계속 · `A` 전체 공개 · `F` 전체 화면 · `M` 소리 · `Esc` 닫기
3. **결과 · 다운로드** — 불참자는 *불참 · 재추첨*, 모든 차수를 *당첨자 CSV 다운로드*로 한 파일 저장.

## 개인정보

- 화면에는 가린 이름(`홍*동`)과 **휴대폰 뒷 4자리(= 추첨번호)**만 크게 표시합니다. 로또 볼·서바이벌 타일에도 이 번호가 적혀 있어요.
- 원본 이름·번호는 메모리에만 두고 저장하지 않습니다. 차수 결과와 가린 명단만 브라우저(localStorage)에 남습니다.
- 당첨자는 추첨 버튼을 누르는 순간 `crypto.getRandomValues`로 확정되고, 연출은 그 결과를 보여 주기만 합니다.
