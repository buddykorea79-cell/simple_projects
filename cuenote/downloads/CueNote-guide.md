# CueNote(큐노트) 사용 설명서

> 마크다운 한 장으로 무대를 진행하세요.
> 행사 큐시트를 `.md` 한 파일로 만들면, 전체 일정과 단계별 원고·슬라이드·타이머를 휴대폰 하나로 진행할 수 있어요.

---

## 1. 설치하기 (안드로이드)

CueNote 는 **Android 7.0 이상** 휴대폰·태블릿에서 동작해요. (iPhone 은 아직 지원하지 않아요)

1. 휴대폰 브라우저에서 `CueNote-<버전>.apk` 를 내려받아요.
   PC 에서 받았다면 메신저 "나에게 보내기"나 USB 로 휴대폰에 옮겨요.
2. 내려받은 파일을 눌러 열어요.
3. **"출처를 알 수 없는 앱"** 설치를 묻는 화면이 나오면 **설정 → 이 출처 허용**을 켜고 돌아와요.
4. **설치**를 누르면 끝! 홈 화면에 CueNote 아이콘이 생겨요.

- Play 프로텍트 경고가 나오면 **세부정보 더보기 → 무시하고 설치**를 눌러요.
- 설치가 끝나면 브라우저의 "출처를 알 수 없는 앱" 허용은 다시 꺼 두는 것이 안전해요.
- **업데이트**: 새 버전 APK 를 같은 방법으로 설치하면 기존 앱 위에 덮어써져요.

## 2. 행사 MD 준비하기

| 방법 | 설명 |
| --- | --- |
| 샘플로 시작 | 앱 첫 화면의 **샘플 행사 열기** 또는 함께 받은 `샘플MD/` 파일 |
| AI 로 만들기 | 앱 상단 ✦ **AI 로 만들기** → 대화로 만들기 / 문서로 만들기 (아래 6절) |
| 다른 AI 사용 | `AI스킬/` 의 스킬을 Claude·ChatGPT·Gemini 에 넣고 "CueNote 행사 MD 로 만들어 줘" |
| 직접 작성 | 아래 5절의 문법대로 메모장에서 작성 |

## 3. 진행하기

1. 앱 첫 화면에서 **MD 파일 불러오기**로 `.md` 파일을 올려요. 바로 행사가 등록돼요.
2. **홈**에서 행사 제목·날짜·장소, 전체 일정(예정 시각·배정 시간·실제 시간)을 확인해요.
3. 단계를 누르거나 하단 **입장**으로 단계에 들어가요.
4. 단계 안에서 **‹ ›** 로 원고 한 화면·슬라이드 한 장씩 넘겨요.
5. 상단 남은 시간(▶ REMAINING)을 누르면 타이머가 시작·일시정지돼요.
6. 단계 끝에서 **다음(완료)** 을 누르면 홈으로 돌아가 다음 단계가 선택돼요. 다시 **입장**!

- 단계 화면 하단 가운데 **홈** 버튼이나 상단 **SCENE** 을 눌러도 홈으로 가요.
- **집중 모드** (단계 화면 ⤢ 버튼 또는 `F`): 상·하단 바를 숨기고 원고·슬라이드만 보여 줘요.
  화면 아래쪽을 누르면 다음, 위쪽을 누르면 이전. 원고는 **자동** 스크롤(속도 − +, ⏱ 배정 시간 맞춤)이 되고, 화면을 만지면 멈춰요.
- **단계 끝에서 바로 다음 단계로**: 관리 센터 → 색상/타이머 → 단계 끝에서 '다음' 을 **바로 다음 단계로**, 또는 행사 MD 프론트매터에 `flow: 연속`.

### 페이지 터너 · 키보드

| 키 | 홈 | 단계 |
| --- | --- | --- |
| `→` `↓` `PageDown` `Space` `Enter` | 선택한 단계 입장 | 다음 (원고 한 화면 / 슬라이드 한 장) |
| `←` `↑` `PageUp` `Backspace` | 이전 단계 선택 | 이전 |
| `Esc` `H` | — | 홈 (집중 모드에서는 집중 모드 끝내기) |
| `F` | — | 집중 모드 켜기·끄기 |
| 숫자 (`1` `2` → 12번) | 해당 단계로 바로 입장 | 〃 |
| `P` | 타이머 시작·일시정지 | 〃 |

## 4. 화면 구성

| 화면 | 내용 |
| --- | --- |
| 홈 | 행사 제목·날짜·장소, 전체 일정, 다음 단계 카드 |
| 단계 | 인사말·나레이션 원고(한 화면씩) 또는 슬라이드 발표(한 장씩), 연출 큐, 체크리스트 |
| 에디터 | MD 원문 편집 (✎ 버튼) |

## 5. 마크다운 문법 한눈에

```markdown
---
title: 창립 30주년 기념식
date: 2026-12-05
venue: 본사 대강당
start: 14:00            # 단계별 예정 시각 자동 계산
---

# 준비 사항
- [ ] 무선 마이크 배터리 교체

# 본행사 시나리오        # 본문 없는 # 은 섹션

## 인사말 {time: 10:00, color: amber, who: 대표이사, mic: 단상 마이크}
- **사회자**: 소개 멘트
원고 문단…
> [음향 큐] 등단 시 팡파르
> [주의] 8분 초과 시 수신호

## 발표 {time: 20:00, type: slides}
### 1. 첫 슬라이드
### 2. 두 번째 슬라이드
```

| 속성 | 의미 |
| --- | --- |
| `time` | 배정 시간 (`05:00`, `1:30:00`) |
| `color` | 단계 색: `blue` `red` `green` `amber` `purple` `pink` `cyan` `slate` |
| `type: slides` | 슬라이드 발표 (`###` 마다 한 장) |
| `at` | 지정 시작 시각 (`14:25`) |
| `who` | 담당·연사 |
| `bgm` `cam` `mic` `light` `vtr` … | 기술 큐 뱃지 (자유 키) |
| `remove: true` | 부분 수정에서 그 단계 삭제 |

- 마크다운 표(`| 시간 | 순서 |`)는 일정표로 표시돼요.
- **부분 수정 MD**: 프론트매터에 `mode: partial` → 같은 제목의 단계는 교체, 새 제목은 추가, `{remove: true}` 는 삭제.
- 전체 규칙은 `AI스킬/SKILL.md` 에 있어요.

## 6. AI 로 만들기

앱 **설정 → AI 연결**에서 본인 API 키로 연결해요. (OpenCode Zen · OpenRouter · BizRouter · ChatGPT · Claude · Gemini · 직접 입력)
**모델 목록 불러오기**로 모델을 고르고 **연결 테스트**로 확인하세요. 키는 기기에만 저장돼요.

| 방법 | 흐름 |
| --- | --- |
| 대화로 만들기 | "12월 20일 18시 송년회, 2시간, 대표 인사·시상·경품 추첨" 처럼 말하면 → 계획안 카드 → "공연을 30분으로" 처럼 고치기 → **새 행사로 등록** |
| 문서로 만들기 | 행사 계획서·식순표 문서를 올리면 → CueNote MD 로 변환 → 미리보기·수정 → **새 행사로 등록** 또는 **현재 행사 일부 수정** |

- TXT·MD 문서는 바로 변환돼요. HWP·HWPX·PDF·DOCX·XLSX·PPTX 는 PC 에서 실행하는 kordoc 문서 변환 서버가 필요해요.

## 7. AI 스킬 설치 (다른 AI 에서 CueNote MD 만들기)

| 어디서 | 방법 |
| --- | --- |
| claude.ai | 설정 → 기능 → 스킬 → `cuenote-md-skill.zip` 업로드 → 대화에서 "CueNote 행사 MD 로 만들어 줘" |
| Claude Code | `.claude/skills/cuenote-md/SKILL.md` 위치에 `SKILL.md` 넣기 |
| ChatGPT · Gemini | GPT/프로젝트/Gem 의 지침(Instructions)에 `SKILL.md` 내용을 붙여 넣기 |

다른 AI 가 만든 결과(` ```cuenote ` 블록 안의 내용)는 `.md` 파일로 저장해 앱의 **MD 불러오기**로 등록해요.
앱 **설정 → 스킬** 탭에서 고친 스킬을 올리면 앱의 AI 도 그 규칙을 따라요.
